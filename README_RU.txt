ПАРК НА МЕСТЕ БОЛОТА · АРХАНГЕЛЬСК
Архив проекта, версия от 14.10.2026

Что внутри
  OPEN_PROJECT_Windows.bat   — открыть книгу проекта в браузере (Windows)
  OPEN_PROJECT_Mac.command   — то же для macOS
  site/                      — книга проекта целиком: 3D-модель, прогулка, панорамы, растения, лист А0, смета
  List_A0_genplan_1000.pdf   — лист А0, генплан 1:1000 (прислан отдельным файлом)
  Smeta_i_vedomost.xlsx      — ведомость объёмов и смета с формулами; синие числа можно менять
  renders/                   — 15 визуализаций, 1280 px
  site/img/pano_N.jpg        — 15 панорам 360° (equirectangular), открываются в любом просмотрщике панорам

Архив разбит на 3 части, потому что чат принимает файлы до 30 МБ.
  Распакуйте все три части в ОДНУ и ту же папку — они сложатся в одну папку swamp-park-arkhangelsk.
  Часть 1 — основа (запуск, сайт, кадры, смета). Часть 2 — панорамы 360°. Часть 3 — кадры облёта для браузеров без WebGL.
  Лист А0 в PDF прислан отдельным файлом.

Как открыть книгу проекта
  Сначала распакуйте архив целиком (правый клик → «Извлечь всё»). Изнутри zip-архива проект не запустится.
  Windows: дважды щёлкните OPEN_PROJECT_Windows.bat. Откроется браузер, а рядом окно с локальным сервером —
           не закрывайте его, пока смотрите проект. Если Windows спросит про запуск, нажмите «Подробнее → Выполнить в любом случае».
  macOS:   правый клик по OPEN_PROJECT_Mac.command → «Открыть». Нужен python3 (macOS предложит установить его сам).
  Почему нужен запуск, а не просто index.html: браузеры не дают странице с диска читать модель и панорамы,
  поэтому проект поднимает маленький сервер только на вашем компьютере (localhost). В интернет ничего не уходит.

Для 3D-модели и прогулки нужен браузер с WebGL (Chrome, Edge, Firefox, Safari). Шрифты подгружаются из интернета;
без сети страница покажется системными шрифтами, всё остальное работает офлайн.
